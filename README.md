# AURA OS — site, demonstração e cofre no navegador

Site estático e versão experimental. A demonstração usa memória temporária. O cliente app/ guarda um cofre criptografado no navegador/aparelho atual, com backup e funcionamento offline após o primeiro carregamento. Limpar os dados do site pode apagá-lo: faça backups. Não há sincronização em nuvem. API, PostgreSQL e AURA ID não são hospedados no GitHub Pages. Consulte as limitações no site antes de usar.
